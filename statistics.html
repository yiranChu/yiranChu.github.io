About This Dashboard

This dashboard displays real-time analytics data from Microsoft Clarity using the official Data Export API. Key features:

  • Real-time Data: Updates automatically every 5 minutes
  • Session Analytics: Total sessions and unique visitors
  • Geographic Data: Visitor locations by country
  • Device Insights: Desktop, mobile, and tablet usage
  • Browser Stats: Most popular browsers
  • Page Analytics: Most visited pages on your site

Note: Clarity API provides aggregated data. For detailed session recordings, heatmaps, and user journeys, visit the Microsoft Clarity Dashboard.

API Limits: Maximum 10 requests per day, up to 3 days of historical data
